# README images

These are selected public documentation images. Raw captures and generated review output remain ignored under `.build/`.

| Image           | Source                                                                                                                                                            |
| --------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `assistant.png` | C152 framebuffer capture of the original robot after the October 15, 2026 renderer update.                                                                        |
| `reply.png`     | C152 framebuffer capture during an encrypted reply protocol check, using synthetic text. It does not demonstrate microphone recognition or a live model response. |
| `settings.png`  | C152 framebuffer capture during Settings verification. Battery and link values describe that capture only.                                                        |
| `moods.png`     | Gallery generated by `make avatar-preview` from the actual firmware renderer on the host, with substitute display, clock and input hardware.                      |

The device screenshots retain their original 468 × 466 pixels. They contain no network names, device identifiers, credentials or private conversation text.

To refresh the artwork gallery with the already installed development dependencies:

```sh
make avatar-preview
cp .build/evidence/avatar/moods.png docs/images/moods.png
```

For new device screenshots, follow the [device ownership and capture procedure](../DEVELOPMENT.md#device-checks) and the [serial recorder instructions](../DEVELOPMENT.md#avatar-review). Use synthetic reply text. Review every capture for private content before copying it here, and update this source record when replacing images.

The public-source check permits only the four named PNGs in this directory. Other binary files remain disallowed.
